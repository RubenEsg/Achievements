# Logros de GitHub

| Logro | Cómo se consigue |
|-------|------------------|
| Pull Shark | Fusionar pull requests (2 para el primer nivel) |
| YOLO | Fusionar un pull request sin revisión |
| Quickdraw | Cerrar un issue o pull request en menos de 5 minutos tras abrirlo |
| Pair Extraordinaire | Fusionar un pull request con un commit en coautoría |
| Galaxy Brain | Que acepten tu respuesta en una Discussion |
| Starstruck | Que tu repositorio reciba 16 estrellas |
